# Historias de Usuario - TalkLate

Sacadas de la hoja Entregables de Mapa de Impacto.xlsx. Formato: Como / Necesito poder / Para.

**HU0001** - Como Cliente Traductor, necesito poder recibir entrada del mensaje, para traducir un mensaje de un idioma origen a un idioma destino en tiempo real, para interactuar facil y rapidamente con personas que hablan otro idioma conservando el contexto cultural, el tono y los modismos.

**HU0002** - Como Cliente Traductor, necesito poder seleccionar idioma y region destino, para comunicarse de inmediato sin tener que repetir la configuracion de idioma en cada mensaje.

**HU0003** - Como Cliente Traductor, necesito poder reconocer el idioma origen, para comunicarse de inmediato sin tener que repetir la configuracion de idioma en cada mensaje.

**HU0004** - Como Cliente Traductor, necesito poder consultar idiomas disponibles, para comunicarse de inmediato sin tener que repetir la configuracion de idioma en cada mensaje.

**HU0005** - Como Cliente Traductor, necesito poder crear conversacion, para conversar de forma fluida y continua sin reconfigurar los idiomas ni los parametros en cada mensaje.

**HU0006** - Como Cliente Traductor, necesito poder configurar parametros una sola vez, para conversar de forma fluida y continua sin reconfigurar los idiomas ni los parametros en cada mensaje.

**HU0007** - Como Cliente Traductor, necesito poder mantener el hilo continuo, para conversar de forma fluida y continua sin reconfigurar los idiomas ni los parametros en cada mensaje.

**HU0008** - Como Cliente Traductor, necesito poder consultar historial, para aprender y ganar confianza en el otro idioma apoyandose en conversaciones pasadas.

**HU0009** - Como Cliente Traductor, necesito poder abrir una conversacion, para aprender y ganar confianza en el otro idioma apoyandose en conversaciones pasadas.

**HU0010** - Como Cliente Traductor, necesito poder renombrar conversacion, para aprender y ganar confianza en el otro idioma apoyandose en conversaciones pasadas.

**HU0011** - Como Cliente Traductor, necesito poder eliminar conversacion, para aprender y ganar confianza en el otro idioma apoyandose en conversaciones pasadas.

**HU0012** - Como Cliente Traductor, necesito poder registro de cuenta, para consultar, organizar y reaprovechar conversaciones anteriores, para tener un historial ordenado que sirva de recurso de aprendizaje y referencia.

**HU0013** - Como Cliente Traductor, necesito poder inicio de sesion, para consultar, organizar y reaprovechar conversaciones anteriores, para tener un historial ordenado que sirva de recurso de aprendizaje y referencia.

**HU0014** - Como Cliente Traductor, necesito poder recuperacion de contrasena, para consultar, organizar y reaprovechar conversaciones anteriores, para tener un historial ordenado que sirva de recurso de aprendizaje y referencia.

**HU0015** - Como Cliente Traductor, necesito poder cierre de sesion, para consultar, organizar y reaprovechar conversaciones anteriores, para tener un historial ordenado que sirva de recurso de aprendizaje y referencia.

**HU0016** - Como Cliente Traductor, necesito poder reproducir audio traducido, para sostener una conversacion natural, hablando y escuchando como lo haria en su propio idioma.

**HU0017** - Como Cliente Traductor, necesito poder entregar por el mismo canal, para sostener una conversacion natural, hablando y escuchando como lo haria en su propio idioma.

**HU0018** - Como Cliente Traductor, necesito poder reportar mala traduccion, para contribuir a mejorar la calidad del servicio senalando las traducciones que no fueron correctas o naturales.

**HU0019** - Como Interlocutor, necesito poder recibir mensaje traducido, para participar en la conversacion en el propio idioma y en igualdad de condiciones, sin necesidad de conocer ni operar la aplicacion.

**HU0020** - Como Interlocutor, necesito poder responder en mi idioma, para participar en la conversacion en el propio idioma y en igualdad de condiciones, sin necesidad de conocer ni operar la aplicacion.

**HU0021** - Como Administrador, necesito poder gestionar catalogo de idiomas, para gestionar la configuracion de la aplicacion a nivel de idiomas o regiones

**HU0022** - Como Administrador, necesito poder revisar reportes de mala traduccion, para revisar los reportes de mala traduccion que envian los clientes, para priorizar las mejoras del servicio.
